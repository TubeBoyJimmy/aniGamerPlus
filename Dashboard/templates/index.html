sn_list

格式：
@分類(可空)
sn碼 下載模式(可空) <檔名標題>(可空) {Plex資料夾}(可空) (S季數)(可空) #注釋(可空)
説明
注釋 # 後面的所有字符程序均不會讀取, 可以用於標記番劇名
在一排番劇列表的上方 @ 開頭後面的字符將會作爲番劇的分類名, 番劇會歸類在此分類名的資料夾下
若單獨 @ 表示不分類
用 < 與 > 將自定義的番劇名框起來, 下載時將會使用這個名字作爲番劇目錄名
Plex 模式
用 { 與 } 指定 Plex 資料夾名, 啟用 Plex 命名模式 (檔名格式: 標題 S##E##.mp4)
用 (S##) 指定季數, 如 (S02); 不指定則自動從資料夾名偵測
用 (S##-偏移) 指定季數與分界點, 如 (S02-11): 集數>11→S02(減11), 集數≤11→自動歸S01
若有 {} 但沒有 <>, 檔名標題會自動從資料夾名去掉季數標記推導
